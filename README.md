# IB 做市练习台

一个单文件的浏览器练习工具，用来练习卖方交易台（Investment Bank Sales & Trading）模拟中的两件事：给客户报双边价，以及在交易所拆单对冲。

## 使用

下载 `index.html`，用浏览器直接打开即可，不需要安装任何东西。

## 三种模式

- **报价速算**：连续 20 个询价，每题 30 秒，只练报价。
- **对冲练习**：开局给三笔大头寸，3 分钟内在交易所平掉。
- **完整模拟**：客户询价、交易所对冲、新闻冲击同时进行，询价按先进先出排队，结束后按六项评分并逐笔复盘。

## 评分项

1. COMM 佣金
2. CT 聊天成交笔数
3. 流动性风险（大单是否拆小）
4. FFC 报价失误
5. PnL
6. 平仓效率

没有同场对手可比，分数用的是固定基准，适合和自己上一局比较。

## 模型假设

- 五只虚构股票 AAA 到 EEE，体量不同，体量越小价差越宽、波动越大。
- 某只股票某个数量的价差 =（市价价差基准 + 2 × 每千股加宽 × 千股数）× 体量系数。
- 每笔交易所成交会把价格推开一部分，约 3 秒恢复一半。
- 客户有隐藏的买卖方向，你那一边的报价距 Mid 在 0.45H 到 1H 之间的某个随机门槛以内才成交，H 按询价数量计算。
- 佣金按成交金额的比例计算。

佣金、价差、冲击、波动、时长和报价时限都可以在页面底部的“参数设置”里调整。这些数值是练习用的假设，不代表任何真实平台的参数。
